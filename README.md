# Первое лето

Спокойный градостроитель на пыльной планете. Таймеров нет, проиграть нельзя.

**Играть: https://e-gu.github.io/pervoe-leto/**

Здесь лежит только собранная игра для сайта. Её исходники хранятся в другом месте.

## Как поставить на iPad

1. Откройте ссылку выше в **Safari**. Другие браузеры на iPad тоже умеют, но проще в Safari.
2. Нажмите кнопку «Поделиться» (квадрат со стрелкой вверх) и выберите **«На экран „Домой“»**. Если этой строки не видно, прокрутите список вниз.
3. Нажмите «Добавить». На экране появится иконка «Первое лето» с куполом.
4. Дальше открывайте игру **этой иконкой**. Она откроется на весь экран и без сети.

На компьютере в Chrome или Edge игру можно так же поставить значком «Установить» в адресной строке.

## Где сохранения

Игра сохраняется сама, в памяти этого устройства. Аккаунт не нужен. В меню ⚙ → «Сохранения» есть три ячейки, прежние копии, которые игра откладывает сама, и строка о том, где всё лежит.

Важно на iPad: **у иконки на экране «Домой» своя память, отдельная от Safari.** Колония, начатая во вкладке Safari, у иконки не появится сама. Перенесите её файлом, как описано ниже.

## Как перенести колонию на другое устройство (или из Safari в иконку)

1. Там, где колония есть: меню ⚙ → «Сохранения» → **«Скачать сохранение»**. Получится файл `pervoe-leto-….json`. На iPad он попадёт в «Файлы» → «Загрузки».
2. Передайте файл на другое устройство: AirDrop, почта или iCloud Drive.
3. Там: меню ⚙ → «Сохранения» → **«Открыть из файла»**. Выберите файл. Игра покажет, что в нём лежит, и спросит, прежде чем что-то заменить.

Иногда скачивайте колонию файлом и просто так, на всякий случай.

## Новые версии

Когда выходит новая версия, игра сама возьмёт её при следующем запуске, если есть сеть. Сохранения при этом остаются.
